# Arquivos iniciais — Capítulo 13

Extraia ou copie a pasta completa e abra-a no VS Code.

Antes de executar qualquer arquivo, siga o capítulo para criar sua chave de API, gravá-la com `setx`, reiniciar o VS Code, criar o ambiente virtual `.venv` e instalar `google-genai`.

Execute `teste_conexao.py` primeiro. Uma frase sobre Python confirma que a chave, o ambiente e a internet estão funcionando.

| Arquivo | Finalidade |
|---|---|
| `teste_conexao.py` | Primeira chamada ao Gemini. |
| `memoria.py` | Demonstração de que cada chamada é independente. |
| `personagens.py` | Dicionário com as instruções de sistema que você vai escrever. |
| `chat.py` | Prática acompanhada. |
| `memoria_quebrada.py` | Oficina de depuração. |

Crie `testes.txt` nesta mesma pasta quando o exercício independente solicitar.

Nunca escreva sua chave de API em nenhum destes arquivos. Consulte `solucao/` somente depois da tentativa e da correção.
