# Práticas de Python

18 atividades independentes dos capítulos, adaptadas do projeto `D:\Lista_python`. Todos os seis grupos foram incluídos, inclusive Transformação, oculto na interface original.

Cada arquivo Markdown é a fonte de conteúdo da atividade. O catálogo define a ordem e os grupos. Dados, missões, saídas e dicas foram preservados da versão `app/desafios-api.tsx`, usada pela página original.

Acesso na apostila: `#/praticas`. Cada prática também tem um endereço próprio: `#/praticas/acesso-1`, por exemplo. O progresso é salvo neste navegador, separado do progresso dos capítulos.
As dicas pontuais da versão anterior (`desafios-api.jsx`) também foram incorporadas como dicas extras.
